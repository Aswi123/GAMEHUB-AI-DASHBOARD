# GameHub AI Dashboard

GameHub AI Dashboard is an interactive web-based platform that combines quizzes and AI-inspired dashboards.  
It allows Students to play quizzes, track results, and Admins to manage questions and monitor overall performance.

## Features

### Student Portal
- Register and login.
- Play quizzes with randomly shuffled questions.
- View quiz history and scores.

### Admin Portal
- Create Admin accounts.
- Add new quiz questions dynamically.
- View all students' quiz results.

### Quiz Functionality
- Questions pulled from a base set and Admin-created questions.
- Each question has one correct answer and three wrong options.
- Score is calculated per user and saved using `localStorage`.

## Technologies
- HTML, CSS, JavaScript
- Uses `localStorage` for storing users, admin data, questions, and results.

## How to Use
1. Open `index.html` in a browser.
2. Register as a Student or Admin.
3. Students can start quizzes and view results.
4. Admins can add questions and see all results.
